# LinkedIn Project Description

Built an end-to-end **E-Commerce Sales & Customer Analytics** project in MySQL.

I analysed 400 orders, 100 customers and 981 order items to answer practical business questions around revenue, customer performance, product/category performance, order outcomes and monthly sales trends.

**SQL used:** JOINs, GROUP BY, aggregations, CASE WHEN, subqueries, CTEs, RANK() and window functions.

A key part of the analysis was separating all-status order-item value (£303,468.01) from completed-order revenue (£195,551.92), ensuring the KPI reflected the business question being analysed.

Next step: turning the same dataset into an interactive Power BI dashboard.
