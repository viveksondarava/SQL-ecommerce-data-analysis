# CV Project Description

**E-Commerce Sales & Customer Analytics | MySQL**

- Analysed a synthetic e-commerce dataset of 100 customers, 400 orders and 981 order items using MySQL.
- Built SQL queries using JOINs, aggregations, CTEs, CASE WHEN, subqueries and window functions to answer business questions across revenue, customers, products and order status.
- Calculated completed-order revenue of £195,551.92 and analysed monthly and category-level performance to identify business trends and customer contribution.
- Produced a structured set of business insights distinguishing completed sales from all-status order-item value.
